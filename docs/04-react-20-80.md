# 04. React 20/80

Mục tiêu: học phần React dùng nhiều nhất trong project CRUD.

## Component

Component là function trả về UI.

```tsx
// JobTitle là một component React.
// Component nhận props và trả về JSX để hiển thị trên màn hình.
function JobTitle({company, position}: {company: string; position: string}) {
  return (
    <h2>
      {company} - {position}
    </h2>
  );
}
```

## Props

Props là dữ liệu component cha truyền xuống component con.

```tsx
// Component cha truyền company và position xuống JobTitle.
<JobTitle company="Google" position="Intern" />
```

## State

State là dữ liệu có thể thay đổi và làm UI render lại.

```tsx
// jobs là dữ liệu hiện tại.
// setJobs là function dùng để cập nhật jobs.
const [jobs, setJobs] = useState<Job[]>([]);
```

## Event

Event là hành động người dùng như click, nhập input, submit form.

```tsx
function handleButtonClick() {
  console.log('User clicked button');
}

<button onClick={handleButtonClick}>Add job</button>;
```

## Render list

```tsx
// map biến mỗi job thành một dòng UI.
// key giúp React nhận biết item nào thay đổi.
{jobs.map(function (job) {
  return <JobItem key={job.id} job={job} />;
})}
```

## Controlled input

```tsx
// value lấy từ state.
// onChange cập nhật state khi user gõ.
<input
  value={company}
  onChange={function (event) {
    setCompany(event.target.value);
  }}
/>
```

## Quy tắc quan trọng

- Không sửa state trực tiếp.
- Không dùng DOM query để cập nhật UI.
- UI nên render từ state.
- Component nhỏ và rõ trách nhiệm.
- Props nên có type.
