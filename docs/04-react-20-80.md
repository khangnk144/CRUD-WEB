# 04. React 20/80

Mục tiêu: học phần React dùng nhiều nhất trong project CRUD.

## Component

Component là function trả về UI.

```tsx
// JobTitle là một component React.
// Component nhận props và trả về JSX để hiển thị trên màn hình.
function JobTitle({company, position}: {company: string; position: string}) {
  return (
    <h2>
      {company} - {position}
    </h2>
  );
}
```

## Props

Props là dữ liệu component cha truyền xuống component con.

```tsx
// Component cha truyền company và position xuống JobTitle.
<JobTitle company="Google" position="Intern" />
```

## State

State là dữ liệu có thể thay đổi và làm UI render lại.

```tsx
// jobs là dữ liệu hiện tại.
// setJobs là function dùng để cập nhật jobs.
const [jobs, setJobs] = useState<Job[]>([]);
```

## Event

Event là hành động người dùng như click, nhập input, submit form.

```tsx
function handleButtonClick() {
  console.log('User clicked button');
}

<button onClick={handleButtonClick}>Add job</button>;
```

## Render list

```tsx
// map biến mỗi job thành một dòng UI.
// key giúp React nhận biết item nào thay đổi.
{jobs.map(function (job) {
  return <JobItem key={job.id} job={job} />;
})}
```

## Controlled input

```tsx
// value lấy từ state.
// onChange cập nhật state khi user gõ.
<input
  value={company}
  onChange={function (event) {
    setCompany(event.target.value);
  }}
/>
```

## Quy tắc quan trọng

- Không sửa state trực tiếp.
- Không dùng DOM query để cập nhật UI.
- UI nên render từ state.
- Component nhỏ và rõ trách nhiệm.
- Props nên có type.

## React giải quyết vấn đề gì?

Ở JavaScript thuần, bạn thường phải tự làm 3 việc:

1. Lưu dữ liệu.
2. Tìm DOM element.
3. Sửa HTML bằng tay khi dữ liệu đổi.

React giúp đơn giản hóa bước 2 và 3. Bạn chỉ cần mô tả UI dựa trên state. Khi state đổi, React tự cập nhật DOM.

Tư duy React:

```txt
State thay đổi
  -> React gọi lại component
  -> JSX mới được tạo
  -> React cập nhật phần DOM cần thay đổi
```

Vì vậy trong React, hạn chế dùng:

```ts
document.querySelector(...)
element.innerHTML = ...
```

## JSX là gì?

JSX nhìn giống HTML nhưng thật ra là cú pháp JavaScript mở rộng.

```tsx
function App() {
  const title = 'Job Application Tracker';

  return <h1>{title}</h1>;
}
```

Giải thích:

- Text trong `{}` là JavaScript expression.
- `class` trong HTML trở thành `className` trong JSX.
- Một component chỉ return một root element.

Ví dụ sai:

```tsx
return (
  <h1>Title</h1>
  <p>Description</p>
);
```

Ví dụ đúng:

```tsx
return (
  <div>
    <h1>Title</h1>
    <p>Description</p>
  </div>
);
```

Hoặc dùng fragment:

```tsx
return (
  <>
    <h1>Title</h1>
    <p>Description</p>
  </>
);
```

## Component nên nhỏ như thế nào?

Một component nên có một trách nhiệm chính.

Ví dụ tách cho CRUD:

- `JobsPage`: giữ state, gọi API, xử lý CRUD.
- `JobForm`: hiển thị form và báo dữ liệu submit.
- `JobTable`: hiển thị danh sách jobs.
- `JobRow`: hiển thị một job.
- `StatusBadge`: hiển thị màu trạng thái.

Không nên để một file `App.tsx` chứa toàn bộ form, table, filter, API, validation quá lâu. Phase đầu có thể để chung để học, nhưng khi hiểu rồi nên tách.

## Props chi tiết hơn

Props là input của component.

```tsx
type StatusBadgeProps = {
  status: JobStatus;
};

function StatusBadge({status}: StatusBadgeProps) {
  return <span>{status}</span>;
}
```

Khi dùng:

```tsx
<StatusBadge status="Applied" />
```

Quy tắc:

- Component con không nên tự đoán dữ liệu.
- Dữ liệu đi từ cha xuống con qua props.
- Nếu con cần báo hành động lên cha, truyền callback.

Ví dụ callback:

```tsx
type JobRowProps = {
  job: Job;
  onDelete: (jobId: string) => void;
};

function JobRow({job, onDelete}: JobRowProps) {
  return (
    <button
      onClick={function () {
        onDelete(job.id);
      }}
    >
      Delete
    </button>
  );
}
```

Giải thích:

- `JobRow` không tự xóa dữ liệu.
- `JobRow` chỉ báo lên component cha: user muốn xóa job này.
- Component cha mới là nơi cập nhật state.

## State chi tiết hơn

Không sửa state trực tiếp.

Sai:

```tsx
jobs.push(newJob);
setJobs(jobs);
```

Đúng:

```tsx
setJobs(function (currentJobs) {
  return [...currentJobs, newJob];
});
```

Giải thích:

- React cần mảng mới để biết state đã đổi.
- `...currentJobs` copy item cũ sang mảng mới.
- `newJob` được thêm vào cuối mảng.

Xóa job:

```tsx
setJobs(function (currentJobs) {
  return currentJobs.filter(function (job) {
    return job.id !== jobId;
  });
});
```

Sửa job:

```tsx
setJobs(function (currentJobs) {
  return currentJobs.map(function (job) {
    if (job.id !== updatedJob.id) {
      return job;
    }

    return updatedJob;
  });
});
```

## Form trong React

Controlled form nghĩa là input lấy value từ state.

```tsx
const [company, setCompany] = useState('');

return (
  <input
    value={company}
    onChange={function (event) {
      setCompany(event.target.value);
    }}
  />
);
```

Luồng:

1. User gõ vào input.
2. Browser tạo event.
3. `onChange` chạy.
4. `setCompany` cập nhật state.
5. React render lại input với value mới.

Người mới thường thấy vòng này hơi dài, nhưng nó giúp dữ liệu form luôn nằm trong React state.

## Conditional rendering

Hiển thị theo điều kiện:

```tsx
{jobs.length === 0 ? (
  <p>No jobs yet.</p>
) : (
  <JobTable jobs={jobs} />
)}
```

Giải thích:

- Nếu `jobs.length === 0`, hiển thị empty state.
- Ngược lại, hiển thị table.

Hiển thị loading:

```tsx
if (isLoading) {
  return <p>Loading jobs...</p>;
}
```

## useEffect dùng khi nào?

`useEffect` dùng để chạy side effect.

Side effect là việc liên quan đến bên ngoài quá trình render, ví dụ:

- Gọi API.
- Đọc/ghi localStorage.
- Gắn event listener vào window.

Ví dụ đọc localStorage khi component load:

```tsx
useEffect(function () {
  const savedJobsText = localStorage.getItem('jobs');

  if (savedJobsText === null) {
    return;
  }

  setJobs(JSON.parse(savedJobsText));
}, []);
```

Giải thích:

- Function trong `useEffect` chạy sau khi UI render.
- Mảng `[]` nghĩa là effect chỉ chạy một lần khi component mount.

## Lỗi React thường gặp

1. Quên `key` khi render list.

```tsx
{jobs.map(function (job) {
  return <JobRow key={job.id} job={job} />;
})}
```

2. Sửa state trực tiếp.

3. Gọi function ngay lập tức thay vì truyền function.

Sai:

```tsx
<button onClick={deleteJob(job.id)}>Delete</button>
```

Đúng:

```tsx
<button
  onClick={function () {
    deleteJob(job.id);
  }}
>
  Delete
</button>
```

4. Component quá lớn.

5. Dữ liệu bị lưu ở quá nhiều nơi.
