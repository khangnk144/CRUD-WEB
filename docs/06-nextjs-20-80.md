# 06. Next.js 20/80

Mục tiêu: hiểu phần Next.js cần cho CRUD app.

## Next.js là gì?

Next.js là framework dựa trên React. Nó thêm routing, server rendering, API route và cấu trúc project thực tế hơn.

## App Router

Trong Next.js App Router:

```txt
app/
  layout.tsx
  page.tsx
  jobs/
    page.tsx
```

Ý nghĩa:

- `app/page.tsx`: trang `/`.
- `app/jobs/page.tsx`: trang `/jobs`.
- `app/layout.tsx`: layout chung.

## Client component

Nếu component dùng `useState`, `useEffect`, event handler, cần `'use client'`.

```tsx
'use client';

import {useState} from 'react';

export function JobSearch() {
  const [keyword, setKeyword] = useState('');

  return <input value={keyword} onChange={(event) => setKeyword(event.target.value)} />;
}
```

## Fetch API

```ts
// fetch gọi API từ frontend.
// await chờ API trả kết quả trước khi chạy dòng tiếp theo.
const response = await fetch('/api/jobs');
const responseBody = await response.json();
```

## Cần nắm chắc

- File path tạo route.
- Component nào dùng state/event thì là client component.
- API route chạy phía server.
- Không đưa secret vào client component.
- Tách logic gọi API vào helper khi code bắt đầu dài.
