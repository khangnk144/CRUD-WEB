# CRUD-WEB

CRUD-WEB là pet project học web từ nền tảng đến full-stack thông qua một app **Job Application Tracker**.

Mục tiêu:

- Học CRUD bằng HTML, CSS, JavaScript thuần.
- Làm lại CRUD bằng React.
- Thêm TypeScript, Tailwind CSS, Next.js.
- Thêm API, database, validation, auth và test.
- Giữ code đơn giản, dễ hiểu, có comment chi tiết cho người mới.
- Tổ chức project đủ nghiêm túc để dùng trong CV.
